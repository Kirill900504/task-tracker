## Методика
- Возраст 6–7 лет. Домашнее использование: игра, обсуждение, понимание ситуаций.
- Контактные приёмы только с тренерами и на борцовском ковре.
- Анимации иллюстративные, не являются сертифицированной техникой и не заменяют демонстраций тренера. Нельзя пытаться повторять броски по картинкам.
- Последующие обновления не меняют ключ localStorage `academy-wrestler-v1`, чтобы сохранялся прогресс после перехода внутри того же веб-адреса.

## 2026-11-15 — диагностика старой версии на iPhone, сборка 7.4

- Найдена основная причина возможного несоответствия: ранний значок домашнего экрана iOS привязан к `rawcdn.githack.com` с фиксированным SHA. Такой URL не получает новых коммитов (кеширование URL постоянное); текущие версии публиковались по `raw.githack.com/.../academy-borca-static/...`.
- В интерфейс добавлена явная метка `версия 7.4` и кнопка «Обновить» для проверки публикации и регистрации service worker.
- Service worker перезаписан с новым идентификатором кеша `academy-borca-pwa-7-4`, сетевой приоритет для HTML/JS/manifest, очистка старых кешей после активации, fallback офлайн.
- Ссылка на стабильную ветку не изменена, локальный ключ прогресса сохранён. Синтаксис четырёх встроенных скриптов корректен.
- Важно: установленный значок с фиксированным `rawcdn` URL невозможно перенаправить удалённо. Один раз открыть постоянный адрес в Safari и добавить новую иконку; старую удалить после проверки. При этом localStorage исходного origin может быть недоступен в новом origin.
